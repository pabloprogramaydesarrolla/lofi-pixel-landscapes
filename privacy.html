Privacy Policy

Lofi Pixel Landscapes Uploader · Last updated: 9 October 2026

The Lofi Pixel Landscapes Uploader (“the uploader”) is a private script used only by the owner of the YouTube channel Lofi Pixel Landscapes to publish their own videos. It has no other users. The uploader uses YouTube API Services.

What the uploader accesses

With the channel owner's permission (Google OAuth), the uploader accesses the owner's own YouTube channel to upload videos, set their titles, descriptions, tags, thumbnails and publishing dates, and add them to the channel's playlist. It does not read comments, subscribers, viewers' data or any other account's data.

What is stored, and where

The only stored item is the OAuth access token that Google issues to the channel owner. It is kept in a private file on the channel owner's own computer and is never sent anywhere except to Google's own APIs. The uploader has no server, no database, no analytics and no cookies.

Besides the token, the uploader keeps a local schedule file on the same computer with the titles, publishing dates and video IDs of the channel owner's own uploads. Nothing about any other user or channel is ever stored.

Sharing

No data is sold, shared or transferred to anyone.

Revoking access

The channel owner can revoke the uploader's access at any time from the Google security settings page.

Data retention and deletion

The OAuth token is kept only while the uploader is in use. When access is revoked, or on request to the contact below, the token file is deleted from the computer within 7 days, together with any schedule entries the owner asks to remove. Since no data is held anywhere else, nothing remains after that.

Google and YouTube

This uploader uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
