Lofi Pixel Landscapes Uploader

A small personal tool for one YouTube channel.

Lofi Pixel Landscapes is a YouTube channel of ten-minute pixel-art worlds with original lofi music. Every scene and every note is generated with code by the channel owner.

This uploader is a private command-line script that runs on the channel owner's own computer. It uses the YouTube API Services to:

  • upload the channel owner's own finished videos to their own channel,
  • set each video's title, description, tags, thumbnail and publishing schedule,
  • add each video to the channel's own playlist.

It is not offered to the public, it has no other users, and it never reads, stores or shares anyone else's data.
